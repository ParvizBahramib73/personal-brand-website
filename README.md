# Personal Brand Website

Premium bilingual (English / Persian) personal brand site. Built to communicate an authentic software engineering background, curiosity about AI, and an interest in practical products and entrepreneurship.

## Product principles
- Editorial, warm off-white, accessible, responsive interface
- English-first with complete Persian RTL layout
- Verified experience and projects only; no invented claims or metrics
- Structured editable content, no database or CMS in v1
- Separate routes for languages, articles and future project detail pages

## Intended stack
Next.js (App Router), TypeScript, Tailwind CSS, local content modules, Vercel deployment.

## Status
Project repository initialized. The prior implementation draft is being reviewed before source integration; **this repository is not yet a deployed website**.

## Delivery plan
1. Personal details and brand assets
2. Design and bilingual content system
3. Site implementation
4. Contact security and SEO
5. Accessibility, responsive and RTL QA
6. Deployment, domain, social preview verification and handoff

Keep API keys and other secrets in deployment environment variables, never in commits.
